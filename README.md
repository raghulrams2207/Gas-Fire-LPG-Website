# 🔥 FlameCore — Premium LPG Delivery Platform

A modern, responsive LPG gas delivery website designed to provide customers with a smooth, intuitive, and visually engaging online experience. **FlameCore** combines a bold visual identity, clean layouts, interactive components, and responsive design to demonstrate a modern digital experience for LPG delivery services.

## ✨ Project Overview

FlameCore is a frontend web development project focused on improving how customers explore LPG delivery services online. It features a professional landing page, engaging visual elements, smooth animations, and interactive user interface components.

The project demonstrates practical skills in frontend development, responsive web design, UI/UX design, and JavaScript-based interactions.

## 🚀 Key Features

- **Modern UI/UX:** Clean layouts, bold typography, and a professional visual identity.
- **Responsive Design:** Adaptable layouts for desktop, tablet, and mobile screens.
- **Interactive Elements:** JavaScript-powered interface interactions.
- **Smooth Animations:** Transitions and visual effects for a more engaging browsing experience.
- **Custom SVG Illustrations:** Scalable vector graphics for crisp visuals.
- **Structured Styling:** Organized CSS for consistent layouts, colors, and components.
- **Customer-Focused Layout:** Content organized to make LPG delivery information easy to explore.
- **Performance-Conscious Design:** Lightweight frontend technologies without requiring a large UI framework.

## 💻 Getting Started

Follow these steps to run FlameCore locally.

### Prerequisites

- A modern web browser
- Visual Studio Code
- The Live Server extension for VS Code (recommended)

### Installation

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Open the project folder**

```bash
cd Flame-Core
```

**3. Open it in Visual Studio Code**

```bash
code .
```

**4. Run the website**

- Open `index.html` in VS Code.
- Right-click the file.
- Select **Open with Live Server**.
- Your website will open in your default browser.

You can also open `index.html` directly in a browser if your project does not require a local development server.

## 🌐 Deployment

FlameCore can be deployed as a static website using platforms such as **GitHub Pages**, **Netlify**, or **Vercel**.

### Deploy with GitHub Pages

1. Push your project files to a GitHub repository.
2. Open the repository's **Settings**.
3. Navigate to **Pages**.
4. Select the branch containing your website files and the appropriate root folder.
5. Save the settings and wait for deployment.
6. Open the published URL and verify the website.

### Deploy with Netlify or Vercel

1. Push the project to GitHub.
2. Import the repository into your chosen platform.
3. Configure it as a static website.
4. Leave the build command empty if no build process is required.
5. Set the publish directory to the folder containing `index.html`.
6. Deploy and test the public URL.
